# 成长萌宠 V3.0｜交互升级与 Agent 研发参考说明文档

> **文档用途**：面向接手改造或对齐版本的开发 Agent。本文档完整梳理「成长萌宠 V3.0」在基础对话原型之上完成的所有核心交互升级——涵盖 **GPT-Voice 风格实时语音对话、语音打开作业与无感录音打卡、极简悬浮云龙布局、全屏专注计时模式、以及顶栏积分直达奖励活动卡片**。Agent 可直接对照现有 Web 原型（`/src/`）与 Android 原生参考工程（`/android-app/`），在原有分支上完成对等交互重构。

---

## 0. 核心交互设计原则（升级前必读）

1. **情绪温和，杜绝突兀红**：语音连线、正在收音、打卡录音状态统一采用浅天蓝 / 科技蓝 / 薄荷青色系（`#EAF6FF` / `#2578FF` / `#0EA5A4`），严禁点击录音后由蓝变红制造紧张感。
2. **一按即通，无需长按**：儿童手部操作和口语表达不宜长时间按住按钮；语音对话与作业打卡均采用“点一下进入持续监听，自然说完自动响应”的模式。
3. **对话即主舞台，减少多余控件**：移除底部成排的快捷短语提示胶囊，统一收口为「今天小任务」；让云龙直接下沉贴近底部语音栏，与对话气泡融为一体。
4. **沉浸专注与正向反馈**：任务进入执行阶段切换全屏专注计时，云龙陪跑（专注/休息/庆祝态联动），完成后触发明确成就激励。
5. **合规与权威边界不变**：积分余额、兑换审批、家长未确认时间表及家庭愿望始终受服务端与家长审批约束，客户端只负责展示与提交申请。

## 1. GPT-Voice 风格实时在线语音对话

### 1.1 交互目标
将传统的“按住说话 / 点击发单句”升级为类似 ChatGPT Voice Mode 的**持续在线语音通话体验**，默认以语音为主、键盘文字输入为辅助降级入口。

### 1.2 核心状态与流转闭环
- **核心开关**：`isLiveVoiceSession`（Boolean）
- **状态机闭环**：
  1. **开启**：孩子点击底部主按钮「和云龙语音聊天」或全屏待机页「唤醒云龙，开始实时语音」→ `isLiveVoiceSession = true`，立即进入第一轮倾听，云龙切换为 `LISTENING` 状态。
  2. **自动上屏与回复**：语音识别返回有效文本（`onFinalResult` / `rec.onresult`）→ 自动调用 `sendMessage(transcript)`，云龙切换为 `THINKING`，随后进入 `SPEAKING` 并播放中文 TTS 语音。
  3. **无缝自动续听（关键）**：监听 TTS 播报结束事件：
     - **Web 端**：`utter.onend` 回调触发 `startContinuousListenPass()`。
     - **Android 端**：`MainViewModel` `init` 中监听 `speechSynthesizer.isSpeaking` 从 `true -> false`，若 `isLiveVoiceSession == true`，延时 `220ms` 后自动调用 `beginLiveListeningPass()`，无需孩子再点按钮。
  4. **无声超时容错**：若本轮未检测到声音（如 `no-speech` 或预览环境无麦克风权限），保持 `isLiveVoiceSession = true` 与 `LISTENING` 安静等待状态，不得自动断开报错。
  5. **随时打断与暂停**：
     - 云龙播报中，孩子点击实时连线状态栏或悬浮云龙旁的「打断」按钮 → 立即中止 TTS（`interruptTts()` / `interruptAiSpeech()`）并切回倾听。
     - 点击状态栏右侧「暂停」按钮 → `isLiveVoiceSession = false`，停止识别与播报，恢复常态底部语音按钮。

### 1.3 底部语音栏 UI 规范
- **未连线常态**：右侧小按钮为键盘切换图标（默认隐藏输入框）；主区域为圆角大按钮「和云龙语音聊天」（蓝色主色调 `#2578FF`）。
- **实时连线态**：替换为柔和浅蓝青渐变胶囊条（`#EBF4FF -> #EAF7F8`），左侧展示 4 柱动态声波动画 + 文案（`实时对话中 · 正在听你说` / `云龙正在说 · 点此打断` / `收音中 · 说“打卡完毕”`），右侧放置轻量「暂停」按钮。
- **键盘降级态**：仅在主动点击键盘图标后展示单行输入框，右侧提供「切回语音主模式」麦克风按钮。

## 2. 安静等待全屏模式 & 主人语音欢迎识别

### 2.1 安静等待全屏模式（`isIdleFullscreen`）
- **触发入口**：点击顶栏全屏图标，或直接点击对话区中悬浮的云龙形象。
- **画面结构**：
  - 顶栏左右各保留 1 个轻量按钮：左「打卡记录 (N)」、右「返回对话流」。
  - 中央大面积留白居中展示放大版 `IDLE` 状态云龙（轻柔呼吸缩放）及状态文案「云龙正在安静等你」。
  - 底部收敛为 2 个明确入口：「今天小任务」轻量按钮 + 「唤醒云龙，开始实时语音」主按钮。

### 2.2 主人语音欢迎识别（Owner Voiceprint Gate）
- **设置项（`SettingsAndProfileScreen` / 设置抽屉）**：
  - 开关：「开启主人语音欢迎识别（仅主人可唤醒）」。
  - 可自定义欢迎唤醒语（如 `“云龙你好，我是乐乐”`）并支持录制 2 秒主人声纹样本（`ownerVoiceprintSamplePath` / `audioUrl`）与试听。
- **拦截与放行逻辑（`verifyOwnerWakeAttempt`）**：
  - 当开启守护且已录入主人声纹时，从全屏待机态点击唤醒 / 测试唤醒触发声纹核验：
    - **主人本人**：校验通过，提示欢迎回来并退出全屏待机进入主对话或开启实时语音。
    - **访客 / 非主人声音**：保持 `isIdleFullscreen = true` 与 `CompanionState.IDLE` 不唤醒，弹窗提示并语音播报「声纹没有认出你哦，只有小主人本人可以唤醒我」。
  - 界面保留「测试访客唤醒（拦截）」与「测试主人唤醒（放行）」快捷验证按钮以便联调演示。

## 3. 语音打开作业 + 无感录音打卡 + 云端同步闭环

### 3.1 `CheckinStage` 状态机
定义 4 个阶段：`IDLE` → `CONFIRMING_HOMEWORK` → `RECORDING` → `SYNCING_CLOUD` → `IDLE`。

### 3.2 完整语音交互流程
1. **点名打开作业（`IDLE -> CONFIRMING_HOMEWORK`）**：
   - 孩子语音或文字说出 `“开始打开语文作业”` / `“打开英语作业”` / `“开始跳绳任务”`（或直接点击任务卡上的「语音打卡」）。
   - 系统调用 `matchHomeworkTask(input, tasks)` 按学科/关键词（语文、背诵、秋天、听写、英语、单词、读书、跳绳等）匹配任务；未命中具体学科时回落到第一条未完成任务。
   - 云龙进入 `SPEAKING` 状态向孩子二次确认：**「你是说确认打开【XXX】吗？请说“确认”或“是”，确认后我就为你开启打卡录音模式！」**，同时底部弹出可点选的确认横幅作为无麦辅助。
2. **确认开启无感录音（`CONFIRMING_HOMEWORK -> RECORDING`）**：
   - 孩子说出 `“确认”` / `“是”` / `“好”` / `“没错”`（或点击横幅「确认，开始录音」）。
   - 自动写入麦克风授权并启动本地音频录制（Web `MediaRecorder` / Android `AudioRecordingManager` 生成 `.m4a`）+ 秒表计时。
   - **视觉表现**：底部出现柔和浅蓝青提示条（`打卡录音中 · 任务名 + 00:12`），明确引导「无需按住，完成后说“打卡完毕”」，云龙切换至 `LISTENING` 安静陪伴。
3. **语音结束与同步云端（`RECORDING -> SYNCING_CLOUD -> IDLE`）**：
   - 孩子说出 `“打卡完毕”` / `“打卡完成”` / `“完成了”` / `“结束了”`（或点击横幅「打卡完毕」按钮）。
   - 自动停止录音、`checkinStage` 切为 `SYNCING_CLOUD`（云龙切为 `THINKING`），生成云端记录编号（`CLD-yyyyMMdd-XXX`）。
   - 将对应任务状态更新为 `COMPLETED` 并附带 `语音打卡 X 秒已同步云端`，录音记录写入云端/本地记录列表（`SYNCED_CLOUD`），云龙切换为 `CELEBRATING` 状态语音报喜，孩子可在「打卡记录」中随时回听。

### 3.3 作业图文详情查看
- 点击任务卡片任意行或右侧「详情」打开作业详情弹窗，完整展示：
  - `detailContent`（如语文周末背诵《秋天》《江南》、听写词语带拼音、跳绳/阅读要求；英语重点句型词汇与不漏页读书范围）。
  - `teacherReminder`（如“老师小提醒：不漏页读书，战胜遗忘”）。
  - 作业参考图片（如 `img_homework_chinese` / `img_homework_english`）。
  - 快捷操作：「发起求助（`HELP_REQUESTED`）」「申请调整时间（`TIME_ADJUST_REQUESTED`）」「开启语音打卡」。

## 4. 今日极简化布局优化（减噪 + 云龙悬浮融合）

相比早期版本「云龙单独占据中上部大区域 + 底部 6 个快捷短语胶囊」的设计，当前版本完成以下精简：

1. **移除冗余短语提示与分割线**：
   - 删除底部一排快捷指令胶囊（如“开始语文作业”“我有心事想说”“我要记录想法”等），避免多按钮分散儿童注意力。
   - 移除宠物舞台与聊天记录区之间的水平分割线。
2. **云龙下沉悬浮于对话流底部（贴近语音按钮）**：
   - 主画布采用单一 `Box` / `relative` 叠层容器：聊天流铺满整个可用高度，底部预留约 `210dp`（Web `pb-[210px]` / Android `bottom = 212.dp`）留白缓冲。
   - 容器最底部叠加 `128dp` 高的半透明浅蓝渐变遮罩，让滚动文字从云龙后方柔和隐去。
   - **悬浮锚点**：`YunlongStage`（`floating = true`）直接锚定在底部语音对话栏正上方，使云龙的视线与位置紧贴孩子点击说话的拇指区，增强“面对面实时语音聊天”的临场感。
3. **统一单一入口「今天小任务」**：
   - 在悬浮云龙正下方（以及全屏待机页底部语音按钮上方）仅保留 1 个胶囊按钮「今天小任务（· 未完成数）」，点击即在对话流中唤起 `TaskManagementCard`。

## 5. 全屏专注计时模式（`开始` -> 专注 / 休息 / 完成）

1. **任务卡按钮简化**：
   - 将任务卡片的「开始计时」简化为「**开始**」，降低低年级阅读门槛。
2. **进入全屏专注界面（`startFocusTask`）**：
   - 点击「开始」后，若当前正处于 `isLiveVoiceSession`，先安静暂停实时语音会话以免环境音干扰专注。
   - 任务状态更新为 `IN_PROGRESS`，进入全屏专注计时界面，计时器从 `00:00` 启动，云龙进入 `THINKING` 专注陪伴态（「云龙正在陪你专注」）。
3. **专注页极简三区结构**：
   - **顶栏**：左「收起」（关闭专注屏返回对话流）、中「学科 · 专注计时/休息中」徽标、右「作业内容」（点击可随时弹窗查看该作业具体图文内容与老师提醒，**弹窗期间不中断计时状态**）。
   - **中央陪伴区**：作业标题 + 放大版云龙动画 + 超大等宽数字计时器（`MM:SS`）+ 预计耗时与积分提示。
   - **底部双按钮**：
     - 左「**暂停休息 / 继续**」（`toggleFocusPause`）：暂停时冻结计时秒数，云龙同步切换为 `RESTING` 休憩态（文案「暂停休息中 · 云龙陪你歇会」）；点击「继续」恢复计时并切回 `THINKING`。
     - 右「**完成**」（`completeFocusTask`）：标记任务为 `COMPLETED`（备注 `专注用时 X分Y秒 完成`），退出专注屏，在对话流写入表扬气泡，云龙进入 `CELEBRATING` 并触发全屏碎纸屑/成就庆祝弹窗（`TaskCelebrationModal`）。

## 6. 顶栏积分直达「积分奖励活动」展示卡片

1. **顶栏直达交互**：
   - 顶栏右侧积分按钮（图标 + `{totalPoints}分`）点击后，不再仅发一条文本消息，而是**直接打开专属的「积分奖励活动」弹窗/底部面板**（Web `showPointsSheet` / Android `Dialog` 包裹可滚动 `PointsRewardsCard`）。
   - 对话流中通过语音/文字查询积分时，仍内嵌复用同一套 `PointsRewardsCard` 组件。
2. **`PointsRewardsCard` 视觉与功能规范**：
   - **积分总览横幅**：左侧突出显示当前可用积分与「服务端记录/校验」说明；右侧高亮徽章展示「**可兑换 X 项活动**」（动态统计 `redeemStatus == AVAILABLE && totalPoints >= costPoints` 的数量）。
   - **最近积分明细**：精简展示最近 2 条加分流水，帮助孩子建立“认真完成任务 → 获得积分”的正向关联。
   - **全部分类筛选**：横向支持全部 5 个分类（`全部活动` / `陪伴` / `玩乐特权` / `兴趣体验` / `实物`）；Android 端使用 `LazyRow` 保证小屏完整滚动切换不裁切。
   - **奖励活动列表状态区分**：
     - 积分充足且可申请：显示绿色「**可兑换**」标签 + 主色「**申请兑换**」按钮（点击后状态变为 `PENDING_PARENT` 等待家长确认，不可客户端直接扣分）。
     - 积分暂不足：按钮位置改为柔和灰底「**还差 X 分**」状态提示，避免误触与挫败感。
     - 已申请/已审批：清晰展示「待家长确认」「兑换成功」或「未通过（含原因）」。

## 8. Agent 改造验收清单（Checklist）

Agent 在旧版本基础上完成本次交互升级后，请逐项核验：
- [ ] **语音交互**：点击底部语音按钮直接进入在线倾听状态，色调为温和蓝青色（无红色警示），AI 说完后自动续听，支持随时打断与暂停，默认隐藏键盘框。
- [ ] **声纹与待机**：全屏待机态可正常放大居中显示云龙；开启主人声纹后，访客测试会被拦截且不离开待机态，主人可通过。
- [ ] **语音打卡闭环**：说出「开始打开语文作业」触发二次确认 → 说「确认」进入无感计时录音 → 说「打卡完毕」自动生成 `CLD-*` 编号、标记任务完成并写入录音记录。
- [ ] **极简布局**：底部无多余短语胶囊；云龙悬浮在对话流底部渐变层上方、紧贴语音栏；仅保留单个「今天小任务」入口。
- [ ] **全屏专注**：任务卡点击「开始」进入全屏专注计时，右上角可随时查看「作业内容」，支持「暂停休息（`RESTING`）/继续（`THINKING`）」与「完成（`CELEBRATING` + 庆祝弹窗）」。
- [ ] **积分直达卡片**：点击顶栏积分直接弹出奖励活动面板，显示「可兑换 X 项活动」、5 个完整分类、以及「可兑换 / 申请兑换 / 还差 X 分 / 待家长确认」状态。
